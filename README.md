# Memory Game

Игра на поиск пар. Нужно открывать карточки по две и запоминать их расположение, чтобы найти все 8 пар за наименьшее число ходов.

## Возможности

- 16 перемешанных карточек, 8 пар изображений
- счётчики ходов и найденных пар
- несовпавшая пара закрывается через 1 секунду, пока она открыта, другие карточки выбрать нельзя
- кнопка «Новая игра» работает в любой момент и сразу сбрасывает поле
- модальное окно победы с количеством ходов
- таблица лидеров с 10 лучшими результатами, данные хранятся в `localStorage`
- модальные окна закрываются кнопкой, кликом по фону и клавишей Escape

Вся разметка создаётся через JavaScript, в `<body>` файла `index.html` находится только `<script>`.

## Технологии

HTML, CSS, JavaScript и сборщик Vite.

## Запуск локально

Нужен установленный [Node.js](https://nodejs.org/).

```bash
git clone https://github.com/<ваш-логин>/memory-game.git
cd memory-game
git checkout memory-game
npm install
npm run dev
```

Приложение откроется на http://127.0.0.1:3000.

## Команды

| Команда           | Что делает                           |
| ----------------- | ------------------------------------ |
| `npm run dev`     | запускает сервер разработки          |
| `npm run build`   | собирает приложение в папку `dist`   |
| `npm run preview` | запускает собранное приложение       |

## Структура проекта

```
src/
  main.js         сборка интерфейса и подключение игры
  game.js         состояние и правила игры
  cards.js        набор карточек и перемешивание
  modal.js        общий компонент модального окна
  victory.js      содержимое окна победы
  leaderboard.js  содержимое таблицы лидеров
  storage.js      чтение и запись результатов в localStorage
  dom.js          хелпер для создания элементов
  style.css       стили
```
